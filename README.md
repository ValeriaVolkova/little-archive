# Drawkeeper — веб-версия

Рабочий прототип для Windows и iPhone. Нативный проект SwiftUI в родительской папке сохранён отдельно. Автоматического преобразования JavaScript в SwiftUI нет: утверждённые экраны и сценарии будут перенесены в нативный интерфейс, IndexedDB заменён на SwiftData/FileManager.

## Запуск на Windows

Из этой папки выполните `node server.mjs` и откройте http://127.0.0.1:4173/. Нужен Node.js. Установка npm-пакетов не требуется. Этот локальный адрес доступен только на компьютере; для iPhone используется опубликованный HTTPS-адрес.

## Что работает

- Главная с семейной сводкой, коллекциями по возрасту и шестью последними добавленными работами.
- Профили детей, цвет и вычисляемый возраст. При создании первого профиля нужны имя и дата рождения. Для 29 февраля в невисокосный год годовщина приходится на 28 февраля.
- Одна фотография для новой работы, замена до сохранения и независимая локальная копия оригинала. Существующие работы и восстановленные старые черновики сохраняют все фотографии и выбор обложки.
- Семейная галерея, поиск, категории, избранное, комбинируемые фильтры по ребёнку, возрастному периоду и году, сортировки.
- Просмотр, редактирование, подтверждение удаления, увеличение фотографии.
- Поворот и прямоугольная обрезка с возможностью вернуть оригинал.
- Альбомы со ссылками на работы, перестановкой кнопками и перетаскиванием.
- PDF A4 с обложкой, стилями Minimal/Warm, подписями и предупреждением о разрешении.
- ZIP-экспорт оригиналов, изменений и JSON-метаданных; проверка CRC32, безопасных путей и связей перед объединением по ID.
- Русский/английский интерфейс; адаптивная мобильная компоновка.

При первом открытии приложение предлагает создать профиль. Демонстрационные иллюстрации доступны отдельно по кнопке «Посмотреть демо» и не сохраняются в личный архив.

## Хранение и перенос

Фотографии и метаданные хранятся в IndexedDB этого браузера и этого адреса сайта. Запись файлов и метаданных выполняется одной транзакцией. При неудаче существующий архив не перезаписывается. Для новых работ фотографии и поля автоматически сохраняются в локальный черновик. Дождитесь статуса «Черновик сохранён на устройстве» перед закрытием вкладки. После повторного открытия доступна кнопка продолжения. Черновики редактирования существующих работ пока не поддерживаются; незавершённые черновики не входят в ZIP.

Компьютер, Safari на iPhone и локальный адрес имеют отдельные архивы. Для переноса: Настройки → Экспортировать ZIP → сохранить файл → открыть сайт на другом устройстве → Восстановить из ZIP. Покупки в ZIP не включаются. Этот формат ещё нужно реализовать в будущем iOS-импортёре; текущий Swift-проект его не читает.

Не используйте приватный режим. Очистка данных сайта или удаление браузера может удалить архив. Сохраняйте ZIP вне браузера. Приложение не загружает фото на сервер; хостинг передаёт только файлы приложения и демонстрационные изображения. Приватный адрес хостинга может запрашивать вход владельца.

Service Worker сохраняет оболочку после первого успешного онлайн-открытия. Офлайн-запуск зависит от сохранности браузерного кэша. На реальном Safari и в авиарежиме пока не проверено. Для обновления закройте все вкладки приложения и откройте снова.

## Границы прототипа

- Нет StoreKit/Premium, лимита 40 работ, системного сканера, ручной коррекции перспективы и выпрямления. Они остаются задачами нативной версии.
- Камера вызывается через системный выбор фотографии браузера, а поддержка HEIC зависит от браузера. Для JPEG приложение предлагает дату из EXIF DateTimeOriginal, если её можно надёжно прочитать. При отсутствии метаданных используется текущая дата. Вручную выбранная дата сохраняется при замене фото.
- Максимум 128 MiB на фотографию, 120 мегапикселей, ZIP до 1 GiB и 10000 файлов. Импорт принимает ZIP, созданный этой веб-версией (без сжатия/ZIP64).
- PDF создаётся постранично примерно в 200 dpi; текст растеризован. Встроенный предпросмотр показывает первые три страницы, скачанный PDF содержит весь альбом. Книга из 100 работ на iPhone пока не испытана.
- Браузер сам определяет доступное место. Это версия для проверки продукта, не принятый релиз нативного MVP.

## Проверки

`npm test` проверяет возраст, Dashboard, комбинированные фильтры, даты EXIF и совместимость хранения и ZIP. `npm run test:storage-browser` проверяет основные сценарии в изолированном Chromium; настройка описана в [инструкции проверки](IPHONE-CHECK.md).

В браузере проверены: загрузка демо, генерация и скачивание PDF из четырёх работ, проверка и восстановление ZIP из трёх работ, редактирование названия/поворот и сохранение после перезагрузки. Реальный iPhone, нехватка места, прерывание браузерного процесса и нагрузка PDF 100 работ требуют отдельной приёмки.

Статические файлы — `dist/`; PDF-библиотека включена локально с MIT-лицензией. Серверная база данных, аналитика и внешние CDN отсутствуют.

### Обработка фотографий в веб-версии

Координаты `cropSettings` нормализованы в системе координат оригинала с учётом EXIF-ориентации. Поле `rotation` задаёт последующий поворот по часовой стрелке. Архив хранит одну готовую JPEG-версию в существующем `editedPath` и использует её для миниатюры, просмотра и PDF. Предел готового кадра — 4096 пикселей по длинной стороне. Пропуск обработки сохраняет только оригинал и миниатюру. ZIP v1 включает исходный файл, параметры и обработанную версию.

Для HEIC сначала используется декодирование браузером. Резервный локальный декодер — CSP-сборка [heic-to 1.6.7](https://www.npmjs.com/package/heic-to/v/1.6.7), файл `dist/csp/heic-to.js` из пакета. Лицензия поставляется рядом с ним в `dist/vendor`. Декодер входит в автономный кэш и запускается по необходимости.
